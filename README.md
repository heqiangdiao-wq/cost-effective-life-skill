# 高性价比人生（cost-effective-life）

**把《高性价比人生指南》用成两样东西：一把验伪的尺子，和一条降到能起步的门槛。**

直接说它管什么：

- 你刷到的养生说法、长辈的劝告、朋友的推荐、网上的产品——**书里到底怎么说**，是真、是半真、还是书里明确不要。
- 书里说对的事，**你为什么做不起来**——给一个今天就能做的起步动作，而不是又一条收藏。

基于 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)《高性价比人生指南》正文（CC BY 4.0）做的独立技能，适用于支持 `SKILL.md` 的智能助手。**这不是原作者的官方技能**，见文末「来源与许可」。

## 它和同题材的另外两个技能差在哪

这个题材已经有两个实现了。**如果不做差异化，第三个就没有存在的意义**，所以先把差别摊开：

| | 上游官方 `life-decision-guide` | `life-development`（Chami537） | **本技能 `cost-effective-life`** |
| --- | --- | --- | --- |
| 一句话 | 查了再答 | 陪你理清 | **验伪 + 落地** |
| 拿什么来找它 | 一个具体决策问题 | 一段人生处境或困惑 | **一个刷到的说法、别人的建议**，或一段处境 |
| 它做什么 | 检索正文 + 按书的算法排序 | 理解处境 + 权衡五个维度 | **拆句 → 判真假 → 溯源 → 降门槛 → 给今日动作** |
| 交回什么 | 3–7 条排序好的清单 | 对话式分析 | **按类给结构**：观点类固定五点，处境类直接答 |
| 独有 | 程序化排序、当场从 `index.html` 抠算法 | 情绪承接、可逆的小试验 | **流行说法验伪表 + 降门槛规则 + 两套输出结构** |
| 缺什么 | 冷；不管「知道但做不到」 | 不排序；不管「我刷到的说法」 | —— |

一句话：那两个技能回答**「我该怎么办」**，这个技能回答**「我听到的这句话是不是真的，以及真的话我该怎么开始做」**。

## 三处结构性差异

**1. 验伪层（`references/hacks.md`）**
把流行说法拆成可检验的句子，逐句对书溯源，给四档判定：✅ 书里支持 / ⚠️ 半对 / ❌ 书里明确不要 / ❓ 书里没写。已收录当下最火的十来条，包括大水理论、大睡理论、薄肌理论、黄毛思维、小水理论、大菜理论、戒色理论、16:8 轻断食、打卡减肥、一天一万步、保健品补剂、防蓝光眼镜，另有二十多条一句话快速索引。

举个表里现成的例子——**「大水理论」是半对半错**：把含糖饮料换成白水，书里支持（第 2 节第 7 条，A 级）；但「每天必须喝够 2 升」书里明确不要（第 6 节第 14 条：有人专门追过「每天 8 杯水」的出处，**一项支持它的研究都没找到**）。同一个梗，一半站得住，一半站不住——**不拆句就只能整句判错**。

**2. 降门槛层（`references/downgrade.md`）**
书里标 `毅力=是/些` 的条目，就是「知道但做不到」的来源。这一层把这类条目降成起步版，强制带齐三件：**触发器**（绑在已经固定发生的事上）、**最小动作**（状态最差也做得完）、**达标口径**（自己能查）。

纪律写得很死：**只降起点，不改书的结论和剂量**——「做 2 个深蹲」是入口，「2 个深蹲就够了」是改书。同时划了不能降的范围：安全类 0/1 动作、急救时间、医疗剂量、法律期限、疫苗，这几类的剂量本身就是内容。

**3. 按输入分成两套结构**
先分清对方是哪一类来的人：**处境类**（讲自己的情况问该怎么办）→ 直接检索书里相关条目、结合处境回答，不套模板；**观点类**（带来一个说法问它怎么样）→ 固定五点：① 一句话判定 → ② 拆成小观点逐条对原文 → ③ 对的地方 → ④ 错的地方 → ⑤ 建议，**不加第六块**。

两套结构分开走，补上了同题材技能「一头太冷、一头太软」的中间态，也避免了拿一个模板回答所有问题。

## 输出长什么样

**观点类** —— 问「薄肌理论靠谱吗？」

> **① 判定：⚠️ 半对。** 练力量这半边书里支持；把「薄」理解成节食，书里明确不要。
>
> **② 拆开对原文**
>
> | 拆出来的句子 | 判定 | 出处 |
> | --- | --- | --- |
> | 该练力量、要线条 | ✅ | 第 2 节第 16 条（每周做 30–60 分钟力量训练） |
> | 靠节食、断食压体脂 | ❌ | 第 28 节第 1 条（不要用极端节食、断食或催吐来控制体重） |
> | 靠手环、体脂秤量化管理 | ❌ | 第 6 节第 8 条（不要指望手环/手表的运动量化帮你减重） |
>
> **③ 对的地方**：做力量训练的人死亡风险低 10%–17%，且每周 30–60 分钟时降幅最大，再多练不会多出好处。
>
> **④ 错的地方**：把「薄」理解成饿出来的瘦，正好撞上第 28 节第 1 条——严重节食的女生出现进食障碍的概率是不节食者的 18 倍。拿设备量化是另一条被否掉的做法。
>
> **⑤ 建议**：① 只从「练」这一侧进——每次坐下之前做 5 个深蹲；② 别碰节食，也别把手环当方法（第 6 节第 8 条已否）；③ 连做两周稳定后，接第 2 节第 16 条的完整版：一周两次、每次 20 分钟。

**处境类** —— 说「每天下班都很累，还想学点东西，怎么开始？」

> 不问完整人生规划，直接检索第 3 节（精力）和第 23 节（学什么技能），给一到两个动作，每个带触发器、最小动作、达标口径，并标出处。

## 怎么用

装好后直接说，例如：

> 用高性价比人生帮我看看，「薄肌理论」到底靠不靠谱？健身博主都说要练薄一点。

> 我刷到说一天必须喝 2 升水能排毒，我妈现在天天灌，这说法对吗？

> 早睡的好处我都懂，但每天都拖到两点，帮我定个能做到的起点。

> 两份工作，一份钱多一份轻松，怎么选？

也支持直接问决策：**该不该 / 值不值 / 划不划算 / 这样犯法吗 / 能领什么 / 出事了先做什么**。

不必先填问卷。助手会按问题补问必要背景，通常一轮一到三个，只问会改变结论的信息。

## 安装

把整个仓库放到助手的技能目录，**文件夹名用 `cost-effective-life`**。

**Codex**

```powershell
$skillRoot = if ($env:CODEX_HOME) { Join-Path $env:CODEX_HOME 'skills' } else { Join-Path $HOME '.codex\skills' }
New-Item -ItemType Directory -Path $skillRoot -Force | Out-Null
git clone https://github.com/heqiangdiao-wq/cost-effective-life-skill.git (Join-Path $skillRoot 'cost-effective-life')
```

macOS / Linux 用 `${CODEX_HOME:-$HOME/.codex}/skills` 即可。其他支持技能的助手，按其安装方式导入整个文件夹。目标文件夹已存在时先检查内容，别覆盖自己的修改。

装完新开一个会话；技能列表没刷新就重启客户端。核心功能（判定、降门槛、快照检索）**不需要联网**，只有核实现行政策、研究等信息时才需要。

## 更新

以克隆方式安装后，在技能目录执行 `git pull --ff-only`。有本地修改时先保留并检查差异。

同步上游指南时，同时更新 `references/topics.md` 里的提交号与日期，并复核 `references/hacks.md` 的数字是否还对得上——**不要只换日期却留着旧数字**。

## 边界

这套技能提供信息梳理与决策支持，**不代替诊断、处方、律师意见或针对具体案件的专业判断**。指南给的是通用口径，制度类内容主要按中国大陆的规定编写，使用时仍需按当事人的地区、身份和当前日期核对官方渠道。

遇到眼前的严重危险（急症、自伤伤人风险、正在进行的法律程序），技能会先帮你求助，不做性价比分析。

指南里的 A/B/C 是**作者的标签**，观察性相关不等于对个人的因果承诺。不同种类的收益（寿命、时间与精力、金钱、人身自由）**不强行折算成一个分数**，无法量化的兴趣、情感和承诺同样算数，最后的选择仍由当事人自己决定。
