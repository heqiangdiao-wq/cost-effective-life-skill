# 证据与适用边界

指南里同时装着研究结果、法规原文、作者的经验、作者的价值判断，还有没核实完的内容。**不要把整本书包装成已经验证的专家结论。**

## 怎么用一条资料

1. **读完整条**，检查适用人群、地域、时间、比较对象、研究终点，以及备注里的限制和争议。
2. **分层识别**：原始研究结果 / 法规原文 / 作者对它们的解释 / 作者的行动建议。后一层不能自动获得前一层的证据强度。
3. **数字确实影响选择时**，再去看原始来源。不要为了让回答显得可靠而堆统计数字。
4. **查不到或无法联网时**，说明尚未核验，**不编标题、DOI、文件号、时间、金额或「已查证」的结论**。仍可给出不依赖这些数字的行动框架和核实入口。

## 什么需要按当下重新核对

- **补贴、医保、公积金、税务、学费、招录门槛、签证、法律条款、办理时限**：必须按当事人的地区、身份和**当前日期**去查发布机关原文或官方办事指南。
- 区分**草案 / 征求意见稿 / 已公布但尚未生效 / 现行规定**；区分全国原则、地方执行口径、单次招录公告。文件日期或书里写的「新规」字样，**不能证明已经生效**。
- 书里那些绝对化标题（「一律」「只有」「都能」「一定」）尤其要查例外和前提。**不能把规避风险的保守建议直接说成法律禁令。**
- **医疗急救、筛查、药物和有禁忌的生活干预**：优先用适用于当地和该人群的现行权威指南。不要仅凭书里一条建议指导自行启停处方药。急症时先给可靠的紧急求助动作，**检索不能耽误求助**。
- 需要专业评估的问题：说明该找哪类专业人员、带哪些资料、重点问什么。不以一句「咨询专业人士」代替实际帮助。

## 研究数字不能怎样翻译

- **观察性相关不是干预的因果效果。** 健康人群的生活习惯与寿命相关，不等于让任意一个人照做就能延寿同样幅度。
- **相对风险下降不是下降同样多的百分点。**
- **HR、RR、OR 不是同一个统计量。** 尤其 OR 在常见结局下不能直接当作风险比。
- 保留时间范围、基线风险、适用人群和不确定性。没有基线风险，不能凭空推出个人的绝对收益。
- **不把不同研究、相互重叠干预的收益相加**；不把疾病发病率、某病死亡率、总死亡率混为一谈；不从短期指标直接推出长期寿命。
- **「没有证据显示有效」不等于「已经证明无效」。** 单项小样本结果不能直接变成普适生活法则。
- 指南的 **A 级包含大型队列等，不等于所有 A 级都能证明因果**，也不是临床指南的 GRADE 评级。法律类的 A 级也不能和医学试验作同一种强弱比较。
- **四种口径不互相折算**：寿命、时间与精力、金钱、人身自由。不能把死亡率、收入、时间和关系质量加成一个伪精确的总分。

## 引用与诚实表达

**三种来源必须分清，在回答里也要分开说：**

| 说法 | 用在哪 |
| --- | --- |
| 「指南第 X 节的某条记载……」 | 只读了本地快照，**当前适用情况尚未核对** |
| 「根据某机关现行文件……」（附链接与查看日期） | 本次真的读了当前原文 |
| 「结合你的处境推断……」 | 这是我的判断，不是书里的内容 |

**其他纪律：**

- 优先引用实际阅读过的原始研究、政府办事指南、官方法律文本或权威医疗指南。搜索摘要、营销内容和核实笔记只能当线索。
- 把建议归到指南时，给出**可定位的章名和条目标题**（例如「第 34 节第 1 条（家里的常备药别吃出事）」），不要只报裸条号——这样对方能在更新后的正文里找到，也能识别出过时的历史核实记录。
- 健康风险提醒要与当前情境相称，**不罗列所有罕见灾难**；「帮别人可能出问题」也不能在没有概率资料时暗示普遍高风险。为无证据的精确断言留白，比补一个看起来合理的数更有用。
- 核实记录（上游 `docs/核实记录/`）只作历史过程，**不是现行依据**，本次快照也没有收录它们。

## 判定与证据等级的配合

回答「这个说法靠不靠谱」时，**判定（✅/⚠️/❌/❓）和证据等级是两件事**，不能混着说：

| 情况 | 怎么说 |
| --- | --- |
| A 级条目，说法与条目一致 | 可以直接说书里支持，把数字和出处一起给 |
| A 级条目，但民间版本改了剂量或人群 | ⚠️ 半对，把被改掉的那部分单独指出来 |
| C 级条目（作者推断、或结论只是「没有证据支持」） | 必须写明这是 C 级、是作者的推断，不能当成 A 级结论往外转述 |
| 条目标了「争议」 | 把反方证据也说一句，并说明争议如何影响建议 |
| 条目标了「TODO / 待核实」 | 别当结论用 |
| 检索不到 | ❓ 书里没写。可以给常识判断，但要标明那是常识 |

另外：**不同口径之间不排序**——换钱的和换寿命的分开列，各排各的。性价比档「一般」不等于不该做，只是那笔花销得当事人自己掂量。
