# 性价比档的算法

本文件是从上游《高性价比人生指南》的在线阅读页 `index.html` 里**摘出来的算法片段**，只保留排序时用得到的部分。内容与上游一致，未作改动。

**为什么不做成 HTML**：上游那个页面里带着作者挂的广告位（一个 Minecraft 服务器推广）、Google Analytics 埋点和 Google Fonts 外链。作为资料快照没必要连这些一起分发，所以这里只留纯文本。

## 成本权重（上游原文）

```js
const COST_W = { money:{'0':0,'少':1,'多':2}, time:{'少':0,'中':1,'多':2}, will:{'否':0,'些':1,'是':2} };
```

## 成本分与性价比档（上游原文）

```js
e.cs = (COST_W.money[e.money] ?? 0) + (COST_W.time[e.time] ?? 0) + (COST_W.will[e.will] ?? 0);
e.ratio = e.level === '大' ? (e.cs === 0 ? '极高' : (e.cs <= 2 ? '高' : '一般'))
        : e.level === '中' ? (e.cs === 0 ? '高' : '一般') : '一般';
```

## 怎么读

- **成本分** = 钱的档 + 时间的档 + 毅力的档，三项相加，范围 0–6。三个档位取自条目上那行 HTML 注释里的成本标签。
- `e.level` 是条目的**收益量级**（大 / 中 / 小），同样取自那行标签。
- 落到档位：

| 收益 | 成本分 | 性价比档 |
| --- | --- | --- |
| 大 | 0 | 极高 |
| 大 | ≤ 2 | 高 |
| 大 | 其余 | 一般 |
| 中 | 0 | 高 |
| 中 | 其余 | 一般 |
| 小 | —— | 一般 |

## 使用注意

- **这不是独立核验过的排序标准**，是原书作者按自己的标准定的粗略排序。档位「一般」不等于不该做，只是那笔花销得当事人自己掂量。
- **不同口径之间不排序**：换钱的和换寿命的分开列，各排各的。
- 上游更新后本文件可能过时。核对方式：取上游 `index.html`，搜 `COST_W = ` 与 `e.ratio = `，看是否还与上面一致。
