## 条目格式与检索

一条长这样：

```markdown
### 7. 不喝含糖饮料，换成无糖的也不算解决
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=死亡率 -->
- 成本：……
- 说人话：……（原书专门把统计量翻成日常说法的栏目）
- 收益：……（原始数字，HR / RR / OR、可信区间、人群、年份）
- 证据等级：A
- 来源：……（多为期刊论文 DOI 或官方文件）
- 备注：……（适用人群、争议、例外、禁忌，**必读**）
```

那行 HTML 注释是给机器读的成本标签：`钱` 取 `0/少/多`、`时间` 取 `少/中/多`、`毅力` 取 `否/些/是`、`收益` 取 `大/中/小`、`口径` 取 `死亡率/金钱/时间/自由`。少数条目末尾还有 `人群=`（怀孕、婴幼儿、孩子、老人、35 岁、60 岁、女性；逗号是「或」、加号是「且」），表示只对这些人有用——对方明显不在那个人群里时，这条可以不推荐。

检索（节文件最大 110 KB，**不要整篇读**）：

```bash
grep -rn '^### ' references/guide/book/ | grep -E '关键词1|关键词2'        # 先看有哪些条目标题
grep -rn -B2 -A8 '关键词' references/guide/book/06-反面清单.md             # 正文里搜，带上下文
sed -n '/^### 16\. /,/^### 17\. /p' references/guide/book/08-别把自己搭进去.md   # 按条号抽一整条
```

**抽出来的条目要整条读完**，尤其是备注栏——适用条件、争议或禁忌都写在那里。检索命中一行不等于理解整条。

## 性价比档怎么算

档位的算法见 [性价比档的算法](guide/ratio-algorithm.md)，那是从上游阅读页摘出来的原文，**别凭记忆写**。

本次快照（2026-10-13）的值是：三项成本各档见上，成本分 = 钱 + 时间 + 毅力三项相加（0–6）；收益 `大` 时，成本分 0 → 极高、≤2 → 高、其余 → 一般；收益 `中` 时，成本分 0 → 高、其余 → 一般；收益 `小` → 一般。

怀疑这个算法过时了，就取上游的 `index.html`，搜 `COST_W = ` 与 `e.ratio = ` 对一下。拿不到算法时，**不报档位**，改成把收益量级和三个成本标签原样列出来，让对方自己掂量。
